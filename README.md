# Sport-Center-Site
This is a college project, made entirely by myself with cooperation of other students from my group, please take note that this is a very basic Web Site, made mostly using Claude.Ai

A responsive sports news portal developed for a college project, heavily inspired by ESPN's clean and grid-based desktop layout. Built entirely using vanilla HTML, CSS, and JavaScript, featuring a dynamic single-page navigation system to switch between Home, News, Search, and Sports categories.
