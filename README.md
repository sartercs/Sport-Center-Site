# Sport-Center-Site
Este é um projeto universitário, desenvolvido inteiramente por mim com a colaboração de outros alunos do meu grupo. Tenha em mente que este é um site bastante básico, feito principalmente com Claude.ai.

Um portal de notícias esportivas responsivo, desenvolvido para um projeto universitário, inspirado no layout limpo e baseado em grade da ESPN para desktop. Construído inteiramente com HTML, CSS e JavaScript puros, apresenta um sistema de navegação dinâmico em página única para alternar entre as categorias Início, Notícias, Busca e Esportes.

A responsive sports news portal developed for a college project, heavily inspired by ESPN's clean and grid-based desktop layout. Built entirely using vanilla HTML, CSS, and JavaScript, featuring a dynamic single-page navigation system to switch between Home, News, Search, and Sports categories.
